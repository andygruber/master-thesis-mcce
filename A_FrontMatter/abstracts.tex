\chapter{Abstract}

Legacy software development environments pose significant challenges by limiting developer productivity and undermining build reproducibility.
Traditional setups rely on manually configured workstations, leading to configuration drift and the well-known ``works on my machine'' problem.
As a result, onboarding new developers is time-consuming, while virtual machines introduce considerable resource overhead.

This thesis investigates whether containerization can modernize development workflows for long-standing native software projects without requiring fundamental changes to the existing codebase.
Controlled experiments are conducted on an industrial C++ software system with decades of accumulated complexity, comparing containerized environments with native and virtualized approaches.
The evaluation focuses on build performance, resource utilization, and the efficiency and reproducibility of environment provisioning.

\begin{sloppypar}
The results show that containers integrate seamlessly into legacy workflows through automated infrastructure-as-code provisioning, IDE integration via DevContainers, and standardized cross-platform CMake-based build configurations.
Toolchain switching time was reduced by 95\,\%---from 12.9 minutes to 37.5 seconds---resulting in substantial improvements for onboarding and multi-version development.
\end{sloppypar}

Performance analysis reveals environment-dependent trade-offs.
Linux-based containers outperformed Windows-native environments by 35--72\,\% in filesystem-intensive workloads, while CPU-bound compilation tasks differed by less than 15\,\%.
Native Linux containers showed virtually no measurable overhead compared to bare-metal execution, whereas hypervisor-based solutions required an additional 5--10~GB of memory.
With compiler caching enabled, optimized containerized workflows achieved up to an 89\,\% reduction in total build execution time.

Overall, the findings demonstrate that containerization provides a viable modernization strategy for build-centric C++ legacy systems, improving reproducibility, productivity, and performance.
