\chapter{Abstract}

Legacy software development environments present substantial challenges that impede developer productivity and compromise build reproducibility.
Traditional setups rely on manually configured workstations, leading to configuration drift and the infamous ``works on my machine'' problem.
New team members may spend days configuring their environments, while virtual machines introduce considerable resource overhead.

This thesis investigates whether containerization can modernize development workflows for long-standing native software projects without requiring fundamental codebase changes.
Through controlled experiments applied to an industrial C++ software system with decades of accumulated complexity, this research compares containerized development environments against traditional native and virtualized approaches across build performance, resource utilization, and environment provisioning efficiency.

The findings demonstrate that containers integrate into legacy workflows through automated provisioning using infrastructure-as-code, seamless IDE integration via DevContainers, and standardized CMake-based cross-platform build configurations.
Toolchain switching time reduced by 95\%---from 12.9 minutes to 37.5 seconds---validating direct improvements for developer onboarding and multi-version development scenarios.

\begin{sloppypar}
Performance evaluation revealed environment-dependent trade-offs: Linux-based containers outperformed Windows-native approaches by 35--72\% for filesystem-intensive operations, while CPU-bound compilation showed modest differences within 15\% across all environments.
Native Linux containers imposed minimal overhead compared to bare-metal execution, whereas hypervisor-based solutions required 5--10 GB additional memory.
Compiler caching amplified these differences substantially, with optimized containerized workflows achieving up to 89\% total workflow time reduction compared to traditional unoptimized approaches.
\end{sloppypar}

Within the context of build-centric C++ workflows, the results demonstrate that containerization principles can be effectively transferred from microservice deployment to legacy system development.
This approach delivers reproducibility, productivity, and performance benefits, making it a viable modernization strategy for preserving established software investments while enabling competitive engineering practices.
